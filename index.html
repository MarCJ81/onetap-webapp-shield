  1. 스캔 — 코드를 붙여넣거나, 파일·GitHub 저장소·배포 URL을 넣습니다. 입력하는 즉시 86개 규칙으로 검사합니다.
    2. 
      
  2. 고치기 — 발견 항목마다 수정 프롬프트 복사를 눌러 Cursor·Claude·Lovable에 붙여넣으면 그 자리에서 고칩니다.
    3. 
      
  3. 막기 — 방어팩에서 호스팅에 맞는 헤더 파일과 CSP를 만들고, 가드레일 키트 ZIP을 저장소 루트에 풉니다.
    4. 
      
  4. 확인 — 의존성 CVE는 OSV.dev 실제 조회, 배포 URL은 헤더·노출 파일 실측. 읽지 못한 항목은 "미확인"으로 남깁니다.
    5. 
      
  5. 공유 — 리포트 탭에서 Markdown/JSON/배지 SVG를 내보냅니다.
