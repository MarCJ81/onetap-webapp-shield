원탭 웹앱 실드 ONETAP WEBAPP SHIELD

개인정보 처리 방침

이 도구는 계정이 없고, 광고·분석 스크립트가 없습니다. 무엇이 이 브라우저 안에 머물고 무엇이 밖으로 나가는지 기능별로 적었습니다.

브라우저 안에서만 처리 (전송 없음)

  • 붙여넣은 코드·업로드한 파일 — 시크릿 탐지, SAST, 점수 계산은 모두 이 탭의 메모리에서 수행됩니다. 서버로 보내지 않습니다.
  • 방어팩·CSP·가드레일 키트 생성 — 로컬 문자열 조립입니다. ZIP도 브라우저에서 만듭니다.
  • 리포트·배지 — 내려받는 파일은 이 기기에 저장됩니다.

기능을 쓸 때만, 해당 서비스로 직접 요청

기능보내는 것받는 곳
GitHub 저장소 스캔저장소 이름(owner/repo)·읽을 파일 경로api.github.com, raw.githubusercontent.com (GitHub)
배포 URL 실측입력한 URL (저장·기록 없음)onetap-shield-probe.onetap-ai.workers.dev (Cloudflare Workers 무료 실측 서버) → 해당 사이트. 서버는 응답 요약(상태 코드·헤더·노출 파일 상태·가린 키 조각)만 돌려주고 페이지 본문을 저장하거나 다시 보여주지 않습니다. 로컬·사설 주소는 브라우저가 직접 확인합니다.

AI 리뷰는 동의 체크박스를 켜야 실행됩니다. 동의하지 않으면 코드는 어디로도 가지 않습니다.

이 브라우저에 저장하는 것

  • shield.settings.v1 — 테마, 선택한 호스팅, CSP 서비스 목록. (코드·파일 내용은 저장하지 않습니다.)
  • shield.byok.v1 — 직접 연결한 AI 키와 모델 이름. 암호화되지 않은 localStorage이며, 공용 PC에서는 쓰지 마세요. '삭제'를 누르면 즉시 지워집니다.
  • sessionStorage: shield.ghtoken — GitHub 토큰(선택). 탭을 닫으면 사라집니다.
  • freeai.visitor.v1 — 무료 AI 체험의 일일 한도 계산용 무작위 ID. 계정·기기 지문과 무관하고, 지우면 새로 생깁니다.

쿠키를 심지 않고, 방문자 추적·광고 식별자를 만들지 않습니다. 서버 로그는 이 정적 사이트를 호스팅하는 플랫폼(GitHub Pages)의 일반 접속 로그 외에 없습니다.

스캔 결과의 정확성

이 도구는 정적 규칙 기반입니다. 규칙에 있는 패턴만 찾으며, 실제 공격·런타임 검증(침투 테스트)이 아닙니다. "발견 없음"이 안전을 보장하지 않습니다. 배포 URL 점검은 실측 서버가 실제 응답을 확인하지만, 실측 서버를 쓰지 못한 경우(로컬 주소·네트워크 문제) 브라우저 CORS 제한으로 읽지 못한 헤더는 미확인으로 표시하며 확인된 것으로 간주하지 않습니다.

발견된 실제 키는 코드에서 지우기 전에 먼저 폐기(revoke)하세요.

문의·삭제

이 사이트는 정적 파일만 배포하며 사용자 데이터를 보관하는 서버가 없습니다. 저장된 설정·키는 브라우저의 사이트 데이터 삭제 또는 각 기능의 '삭제' 버튼으로 바로 지울 수 있습니다.
